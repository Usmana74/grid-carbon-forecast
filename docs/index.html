  • What “carbon intensity” means here: a production-based estimate from Germany’s generation mix and fixed lifecycle emission factors. It ignores cross-border flows, so it differs from official figures and from other trackers.
  • Known limitation: training uses observed/reanalysis weather while live forecasts use forecast weather, so backtest skill is likely optimistic. The live scoreboard is the honest number.
  • Forecast files are committed daily and never rewritten, so the track record is auditable in git history.
  • Not an official or safety-critical service. Data: Energy-Charts (Fraunhofer ISE), Open-Meteo.
